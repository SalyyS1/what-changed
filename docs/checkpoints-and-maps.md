# Checkpoints and maps

**Evidence state: available for the implemented surfaces; real Docker live data is a
known limitation on this machine.**

Checkpoints capture durable collector state at a bounded point in time. A
comparison describes structural field changes and missing collectors; it does
not reconstruct events that were never observed.

The Change Map is contextual to an investigation. The System Map is a bounded
relationship explorer for users who want to ask “what depends on this?”. Both
have a 2D fallback and do not replace the core timeline or investigation flow.
