# Support policy

**Evidence state: available support route; response time and hosted-channel behavior are planned.**

Support is handled through the repository issue tracker or the contact route
listed in [SUPPORT.md](../SUPPORT.md). Include the app version, Windows version,
collector status and a diagnostics export. Do not attach the history database,
raw logs, `.env` files, private paths or screenshots containing personal data.

Security reports belong in [SECURITY.md](../SECURITY.md), not in a public issue.
The first release has no automatic or background update channel. Settings exposes an explicit opt-in
scaffold, but users receive release instructions through the documented manual download path until a
signed feed and release public key are configured.
