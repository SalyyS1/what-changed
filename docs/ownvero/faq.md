# Frequently asked questions

**Evidence state: development-source guidance; no approved owner-workspace installer or completed native acceptance.**

## Does Ownvero build my app?

No. It records intent, preserved behavior, evidence, and owner decisions. Take the
reviewed Markdown brief to the coding AI you already use. It does not deploy your
app or silently edit code.

## Is this an AI IDE or a test safety score?

It is an owner workspace. A passing scenario covers its declared expectation and
context. It cannot certify every behavior, predict all regressions, or guarantee
that a change is safe. Acceptance remains your decision.

## Can I use any preview URL?

Not for durable automated verification. The first supported target family needs
an authorized booking or CRUD preview, trustworthy revision identification,
deterministic locators, roles, and supported adapters. A URL and a build name alone
cannot establish current backend identity. See [Verification](verification.md).

## Does it work offline?

Local planning, reviewed briefs, historical evidence, and export do not require
an account or cloud service. A consented preview session may use the network.
The website demonstration uses synthetic data and never contacts your app.

## Where is the installer?

There is no approved Ownvero public installer. An older unsigned What Changed QA
candidate does not prove the owner workspace. The download page stays unavailable
until an exact artifact and notice set receive release approval. A checksum is not
code signing. Windows x64 is the first platform scope.

## What remains unverified?

Clean-Windows runner packaging, enforceable network limits, native resource
performance, installed acceptance, and repeated use by real owners remain open.
Development source and a synthetic demo are evidence of implementation, not those
acceptance results.

## Is Vietnamese available?

The landing, quickstart, and glossary have Vietnamese versions. Technical reference
pages are currently English. Locale links show available content rather than
implying a complete translation.

## What happens to What Changed?

Legacy local diagnostics and history keep their meaning. The public name and native
assets remain approval-gated. Read [Migration](migration-guide.md) before assuming a
new installer or data path is required.
