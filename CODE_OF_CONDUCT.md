# Code of Conduct

What Changed is a small, local-first project. Contributors are expected to be
kind, specific and patient, especially when discussing privacy, accessibility,
security and evidence limits.

Unacceptable behaviour includes harassment, discrimination, threats, doxxing,
publishing another person's data, or deliberately weakening the non-elevated,
offline and redaction guarantees. Maintainers may remove comments, close
issues, or decline contributions that do not meet these standards.

Report a conduct concern privately through the security contact in
[SECURITY.md](SECURITY.md). Do not include secrets or a database export.
