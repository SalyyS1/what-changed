- The offline loop remains app → confirmed rules → saved request → reviewed Markdown
  brief → verification → explicit owner decision → next request. Imported/manual
  history cannot become a current automated pass.
- The runner panel freezes candidate, scenarios, exact effects, synthetic values and
  optional screenshot permission. Preparation does not start a browser. Login is
  explicit in isolated contexts; remote targets remain unavailable.
- Native supervision owns the suspended process tree before resume. Results carry
  exact run/nonce/order/assertion identity and are persisted by the parent. Missing
  runtime, unknown revision or interrupted execution does not manufacture success.
- Navigation requests cancellation. Unconfirmed termination retains the exact
  session in an app-wide recovery banner with bounded automatic/manual retry until
  matching native terminal status. A cancellation acknowledgment alone is insufficient.
- Captures require session consent, explicit capture and individual review. Durable
  list/delete and seven-day expiry are implemented; portable memory/test exports
  exclude images and credentials. Runnable ZIPs require independent setup and carry
  no live execution authority.
- Journey, 2D, keyboard list and optional 3D share stored facts and exact inspection.
  Comparisons name incompatible revisions; gaps and owner exceptions remain visible.
- The local site builds 19 static pages with search, synthetic interactive demo,
  no-JavaScript documentation, legacy aliases and unavailable downloads. No public
  identity switch, deployment or uploaded binary is implied.
