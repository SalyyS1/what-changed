# Ownvero draft identity

Local review assets only. G2 has not approved a public name or production identity
switch. Native icons, installer artwork, master brand source, binary name, and app
identity remain under their existing owners. No trademark clearance is claimed.

The open frame and inner corner refer to an owner’s explicit boundary and a
reviewable piece of work. They are not a certification or security seal. The mark
uses charcoal and muted green; monochrome and reverse variants preserve its shape.
The wordmark is a typography draft using the installed system sans family, not an
outlined production font asset. Small-size native acceptance remains open.

The [static site](../../../wiki-site/README.md) copies only the draft mark into its
allowlisted output. It never changes the existing export pipeline or tracked
native assets. Production export and display-scaling checks follow G2 approval.
