# Support

What Changed is an unsigned Windows preview release. For useful support,
include the app version, Windows version, the collector name, and the exact
visible symptom. Use **Diagnostics → Export diagnostics** when available; the
export intentionally contains counts and versions, not event rows, paths or
entity names.

Do not attach `events.db`, WAL/SHM files, logs, screenshots with usernames, or
configuration values. Redact paths and account names from any reproduction.

Security issues have a separate route in [SECURITY.md](SECURITY.md). Feature
requests belong in the repository issue tracker after checking
[known limitations](docs/known-limitations.md).
